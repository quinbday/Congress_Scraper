# Congress_Scraper
This code scrapes from (capitoltrades.com)[capitoltrades.com], senate and house committee websites, and yahoo finance to find congress trades from the present day to 2023 and outputs them into an excel file containing the disclosed info from the trade (Politician,	Legislation (House or Senate),	Party,	Trade_Type,	Stock, Date_Disclosed,	Date_Purchased,	Amount,	State_Politician,	Filed_After,	Price_Purchased,	Price_Current) as well as info about the company (Industry,	Sector, State_Company) and the committees the politician is a part of (Committees). It takes around 6 hours to run on my laptop since there are over 3,000 pages on the capitoltrades website.
